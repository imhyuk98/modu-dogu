- X, LINE, Instagram: Simple Icons 13.21.0의 브랜드 SVG 경로를 변경 없이 사용. 전체 라이브러리 설치 없이 필요한 세 아이콘만 포함.

아이콘은 사이트 번들 안에 포함하므로 방문자 브라우저가 외부 아이콘 서버로 요청하지 않습니다. SVG는 장식 요소로 숨기고, 실제 버튼 이름은 화면에 보이는 텍스트로 제공합니다. 공유 대상과 기존 동작·계측은 변경하지 않습니다.
