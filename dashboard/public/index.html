실제 방문 통계를 연결하세요

현재 화면의 예시 수치는 실제 방문 기록이 아닙니다. 아래 설정을 완료하면 실제 통계를 조회할 수 있습니다.

  1. Google Cloud에서 Analytics Data API와 Search Console API 활성화
  2. 서비스 계정 이메일에 GA4·Search Console 읽기 권한 부여
  3. 서버에 GA4 숫자 속성 ID와 서비스 계정 키 등록
  4. 미리보기 대신 인증 모드로 서버 실행

설정 방법은 프로젝트의 dashboard/README.md에서 확인할 수 있습니다.

SNS 공유와 친구 참여

선택 기간·포털·첫 방문 페이지 필터를 적용합니다. 공유 요청은 전송·게시 성공이 아니며, 인스타그램 안내와 링크 복사도 따로 집계합니다. 행별 사용자는 중복될 수 있습니다. 순차 퍼널·완료율·SNS별 신규 유입을 증명하는 수치가 아닙니다. 새 SNS 이벤트는 이번 배포 이후부터 수집됩니다.

유입 페이지와 도구 사용

포털별 유입의 ‘원본 출처 / 매체 분석’ 필터와 함께 적용됩니다.

상위 10,000행 제한으로 일부 행이 생략되었습니다.

출처별 첫 방문

해당 유입에서 기록된 도구 사용

이벤트 횟수는 완료율이 아닙니다. 사용자는 행 간 중복될 수 있으며 이벤트가 없다고 미사용으로 단정할 수 없습니다. 측정은 일부 도구에서만 제공되고 시작·완료 정의가 다릅니다. 첫 방문 이후 다른 페이지에서 사용한 이벤트도 포함됩니다.

포털별 유입

GA4 · 세션 출처 기준

네이버·구글·다음·빙 등을 비교합니다. 포털별 수치에는 검색뿐 아니라 블로그·카페 등의 추천 유입도 포함되며, 자연 검색은 매체가 organic인 세션만 집계합니다.

사용 이벤트

시작·완료·공유 이벤트는 추적이 구현된 도구에 한해 집계됩니다.

GA4는 선택 쿠키에 동의하고 추적이 차단되지 않은 방문을 집계합니다.
자동 갱신은 5분 간격이며, 실시간 외 통계는 처리 지연으로 변할 수 있습니다.
